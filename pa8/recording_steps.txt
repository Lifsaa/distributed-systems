PA8 Recording Steps

Use two terminals.

Terminal 1:
cd /Users/lifsa/Desktop/distributed-systems/pa8
make logs

Terminal 2:
cd /Users/lifsa/Desktop/distributed-systems/pa8

Important:
- Replica numbers are examples.
- If a step says follower, stop a follower, not the leader.
- If a step says leader, stop the current leader.
- If a command says not leader, rerun it with the LeaderAddr it prints.

Before each scenario:
make reset-scenario
make up

Wait until Terminal 1 shows:
CANDIDATE SERVER X WINS THE ELECTION FOR TERM Y

Optional leader check:
make seed

Scenario 1
Purpose: follower failure, leader failure, recovery, final log match.

1. Stop one follower:
docker compose stop replica5

2. Send 20 requests to the current leader:
make load20 LEADER=localhost:5001

3. Stop the current leader:
docker compose stop replica1

4. Wait for new leader, then send 30 requests:
make load30 LEADER=localhost:5002

5. Stop that current leader:
docker compose stop replica2

6. Restart the earlier stopped replicas:
docker compose start replica5 replica1

7. Wait for a leader, send 40 requests, test, save:
make load40 LEADER=localhost:5003
make test-logs
make save-scenario NAME=scenario1

Expected:
PASS logs match

Scenario 2
Purpose: no majority means no leader, then majority returns and logs still match.

1. Start fresh:
make reset-scenario
make up

2. Stop two followers:
docker compose stop replica4 replica5

3. Send 20 requests to the current leader:
make load20 LEADER=localhost:5001

4. Stop the current leader. Only two servers are up now:
docker compose stop replica1

5. Restart one follower to restore majority:
docker compose start replica4

6. Wait for new leader, then send 30 requests:
make load30 LEADER=localhost:5002

7. Stop the current leader:
docker compose stop replica2

8. Restart one previous server:
docker compose start replica1

9. Wait for a leader, then send 40 requests:
make load40 LEADER=localhost:5001

10. Restart final stopped follower, test, save:
docker compose start replica5
make test-logs
make save-scenario NAME=scenario2

Expected:
PASS logs match

After both scenarios, rebuild the submission zip.
